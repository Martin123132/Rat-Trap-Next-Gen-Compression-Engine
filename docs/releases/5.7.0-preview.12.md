# Rat-Trap 5.7 — Library and backup plans public preview

**Compress it. Find it. Get it back.**

[Download Rat-Trap for Windows x64](https://github.com/Martin123132/Rat-Trap-Next-Gen-Compression-Engine/releases/download/v5.7.0-preview.12/Rat-Trap-Windows-x64-setup.exe)

Organise stored work by project, search across your Library, check supported
Vaults and backup histories, and save a manual backup plan for the next run.
The installer also includes the existing compression, Queryable Vault,
structured-data, protection and five guided-practice workflows. No Python,
Codex or Rat-Trap account is required to use the application.

## What is new since the previous public preview

- **Library and project timeline:** explicitly register stored items, group them
  by project, store a folder and record what happened.
- **Search entire Library:** find supported filenames across projects, without
  automatically extracting or unlocking protected items.
- **Restore directly:** select one file from an unencrypted Vault or an exact
  versioned-backup snapshot and restore it into a new folder.
- **Library health:** manually check supported Vaults and completed backup
  versions; availability and dated integrity results are shown separately.
- **Saved backup plans:** remember the source, backup destination and project,
  then explicitly choose **Back up now** to create another version.

Plans are manual: no scheduler, watcher or automatic retention is included.
Live backup repositories are **not encrypted**. The local Library catalogue,
plan paths and receipts are unencrypted metadata. A health result is historical,
not continuous monitoring or an independent backup. Keep originals and an
independent backup; see [exact boundaries](../TECHNICAL.md#exact-feature-boundaries).

## Qualification and limits

The [Library plans qualification record](../../release-manifests/library-plans.json)
and [validation report](../LIBRARY-PLANS-VALIDATION.md) record:

- **704 regression tests run: 703 passed, one skipped.** Native Windows
  symbolic-link creation permission was unavailable for the skipped test.
- **Nine packaged self-test modes passed**, also repeated on an isolated
  installed application. The UI and Library modes share a harness.
- The original local installer passed **230 isolated lifecycle checks**,
  including the specific 5.7.0.11-to-5.7.0.12 upgrade, with no failed checks
  or cleanup errors. Its result does not itself qualify the rebuilt installer.
- An isolated QA-identity build of the public installer recipe passed
  **243 lifecycle checks**, including a 5.7.0.6-to-5.7.0.12 upgrade and a
  deliberately locked Start-menu shortcut. An earlier diagnostic run of the
  original local setup failed a shortcut cleanup check; its repeat passed.
  Both outcomes and the packaging change are documented in the
  [public installer validation](5.7.0-preview.12-validation.md).

The [public release record](../../release-manifests/public-preview.12.json)
identifies the rebuilt normal setup and the separate QA results by hash.

Tests were performed on the Windows 10 development host, not a clean Windows
11 machine. They are functional qualification, not new compression benchmarks
or independent security certification.

The app and installer are **unsigned** and not Microsoft Store-approved.
Windows or organisational security may warn or block the download; do not
disable protection. [Installation guide](../WINDOWS.md).
