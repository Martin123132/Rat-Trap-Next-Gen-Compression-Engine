# Preserved original Rat-Trap experiments

These files preserve the original implementations, notes, benchmark harness
and full-run transcript. They contain a mixture of code, prose and captured
output. They are historical material, not the current supported application
or a set of scripts to run blindly.

The publication tidy-up moved them out of the repository root without
changing their bytes. The original names and paths remain available at their
recorded commits in Git history; historical evidence identifiers are not
rewritten to pretend they originally lived here.
