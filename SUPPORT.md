# Rat-Trap Support

Rat-Trap support and commercial licensing enquiries are handled by
**TWO HANDS NETWORK LTD**.

Current contact: `ollett123123@outlook.com`

## Before contacting support

Please include:

- the Rat-Trap version shown at the bottom of the application;
- the Windows edition, version, and whether it is 64-bit;
- the operation you selected;
- the complete error message;
- whether the source and destination are local, removable, or network storage;
  and
- a minimal reproduction using non-confidential test files, where practical.

Rat-Trap does not upload diagnostics automatically.

## Do not send

Do not email:

- passwords or password hints;
- `.rtrk` recovery keys;
- confidential archives or Sealed Files;
- personal documents or complete file listings;
- payment-card details; or
- any information that is not needed to investigate the problem.

If a filename or path contains personal or confidential information, replace
it with a neutral example before sending a screenshot or error report.

## Useful checks

Before reporting a problem:

1. confirm that the source still exists and is readable;
2. save the output outside the source folder;
3. confirm there is enough free storage for the requested operation;
4. try a small folder containing ordinary test files;
5. retain the original archive and recovery key while investigating; and
6. do not repeatedly overwrite the only copy of important data.

## Security reports

For a suspected security defect, use the contact address above and begin the
subject with `Rat-Trap security report`. Provide the smallest safe reproduction
and the affected version. Do not send a real password, recovery key, or
confidential user data.

## Licence enquiries

Commercial use requires a separate written agreement with TWO HANDS NETWORK
LTD. See `COMMERCIAL-LICENSE.md` for the information to include.
