INSTALL AND OPEN

Run the separately supplied Desktop Preview 2 Setup when you are ready to test
this candidate. It installs for your current Windows account in:
%LOCALAPPDATA%\Programs\Two Hands Network Ltd\Rat-Trap Desktop Preview 2

Setup requires Windows 10 or later, 64-bit. No separate Python installation,
Rat-Trap account, or internet connection is needed for local file operations.
After installation, use the Rat-Trap Desktop Preview 2 Start menu folder.
The application file is named Rat-Trap-Desktop-Preview-2.exe.

Desktop shortcut and Open with integration are optional and initially off.
If you select Open with integration, Setup offers this preview for .gmw and
.rtsf files; your current default apps are not changed. Opening these files
only selects the relevant screen/input. It does not automatically decrypt,
extract, restore, or execute them. Recovery-key files have no association.

A QA-labelled installer uses its own QA-labelled folder and registration.
It does not target the ordinary Desktop Preview 2 installation.

UNSIGNED WINDOWS WARNINGS

Neither this installer nor the application is Authenticode-signed. Windows,
SmartScreen, antivirus software, or an organisation's policy may warn about
or block them. A warning alone does not establish whether a download is safe
or unsafe. Obtain the candidate from a trusted supplier. If blocked or unsure,
stop and ask your administrator or the support contact below. Do not disable
security protection to run it.

SHA256SUMS.txt lists the other application payload files installed by Setup.
The generated uninstaller is not included in that list. Checksums help detect
changed or damaged files, but checksums accompanying a download do not prove
who supplied it or replace a digital signature.

TRY THE APP WITH COPIES

Keep independent backups. Compress copies of a small test folder, save the
archive outside that folder, restore into a different empty folder, and compare
the restored contents with the originals. Do not overwrite originals or make
a preview archive your only backup. Wait for work to finish before closing
the app, rerunning Setup, uninstalling, or disconnecting storage.

Preview 2 adds easier same-session file selection, reported stage and elapsed
time, and completed-result actions. Elapsed time is not an ETA. Open archive
preselects an input in the app. Show in folder opens File Explorer only on your
explicit click. The installer adds no new compression or encryption features.

Compression alone is not encryption. Encryption is optional for supported
formats; a .gmw file is not necessarily encrypted, and a live repository is
not encrypted merely because Rat-Trap created it. Keep passwords and .rtrk
recovery keys safe and separate from protected data. A matching recovery key
can unlock it. Losing the required password and recovery material can make
the data unrecoverable. Restoration may produce unencrypted files.

MORE HELP, REPAIR, AND REMOVAL

README-PORTABLE.txt preserves the original portable-preview guide. Its ZIP
extraction/no-association instructions apply to the portable edition, not this
installer; this README-FIRST.txt explains the installed candidate.

There is no automatic updater. Re-running this compatible installer can repair
its own preview installation and preserve your optional choices. Close the app
after its current operation finishes before repairing or removing it. Setup
does not kill a running compression operation.

Remove Rat-Trap Desktop Preview 2 through Windows Apps settings. Uninstall
removes only its installed files and its own shortcuts/registration; it does
not recursively delete the installation folder. Your archives, recovery keys,
repositories, exports, restored files, and other separate Rat-Trap installations
are retained. User files left in the installation folder keep that folder from
being removed. Keep or delete your own data yourself. Local diagnostics may
remain under:
%LOCALAPPDATA%\Two Hands Network Ltd\Rat-Trap\Diagnostics
