ONE APPLICATION, UPDATED IN PLACE

This unsigned preview updates the existing Rat-Trap Desktop Preview 2
installation. It does not create another ordinary installed product identity.
If not already installed, Setup installs for your current Windows account.
Windows 10 or later, 64-bit is required.

Installation remains:
%LOCALAPPDATA%\Programs\Two Hands Network Ltd\Rat-Trap Desktop Preview 2

Open Rat-Trap Desktop Preview 2 from its existing Start menu folder and choose
Library. Create a project and add existing archives, Vaults or backup
repositories. Your stored files remain in their existing locations.
README-PORTABLE.txt has fuller application and catalogue privacy notes.

Library metadata is plaintext, including project names, paths, notes and
timestamps. An encrypted archive does not encrypt its catalogue entry.
A catalogue reference is not a separate backup. Calendar integration,
scheduled capture and an external API are not included in this stage.

INSTALLATION AND OPTIONAL INTEGRATION

Wait for any operation to finish and close the application before Setup.
Setup does not kill running compression or restore work. Existing optional
desktop shortcut/Open with choices are preserved unless changed explicitly.
Re-running the compatible installer repairs its application files.

On a new installation, desktop shortcut and Open with integration are
optional and initially off. Open with supports .gmw and .rtsf only; existing
default applications are not changed. Opening a file preselects it in the
application and does not automatically decrypt, extract or execute it.
No recovery-key association is added. QA-labelled installers target only
their matching QA-labelled registration and directory.

No separate Python, Rat-Trap account or Codex is required. There is no
automatic updater. This is not a signed or Microsoft Store release.

UNSIGNED WARNINGS

Neither installer nor application is Authenticode-signed. Windows,
SmartScreen, antivirus or your organisation may warn about or block them.
Obtain the preview from a trusted source. If uncertain or blocked, stop
and ask support or your administrator. Do not disable security protection.

SHA256SUMS.txt lists installed payload files except the generated uninstaller.
Checksums detect changes but do not authenticate the publisher.

KEEP YOUR DATA

Use copies for testing, preserve your originals and keep independent backups.
Save archives outside source folders; restore into a separate empty folder.
Compression alone is not encryption. Live repositories, restored files and
Library metadata are not automatically encrypted. Keep passwords and recovery
keys safe and separate from protected data.

Uninstall via Windows Apps settings removes only installer-owned files,
shortcuts and registration. It does not recursively delete its directory.
Your archives, keys, repositories, Library catalogue, exports, restored files
and local diagnostics remain. Unexpected user-created files inside the
installation directory are preserved. Do not store your only data copy there.
