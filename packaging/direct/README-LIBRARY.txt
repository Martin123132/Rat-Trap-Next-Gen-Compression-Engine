YOUR STORED WORK IN ONE PLACE

Choose Library to organise stored archives, Vaults and backup repositories
under projects. Add existing items explicitly; the catalogue does not move,
compress, upload or delete your source data. Project notes and a timeline help
you identify what you saved and when. Saved repository snapshots are specific
versions; a catalogue entry is not a new backup or a promise that later edits
are protected.

The five existing guided walkthroughs remain available in Show me how.
The established compression, Vault, backup, protection and restore tools remain
available. This preview adds organisation, not a new compression algorithm or
archive format. Calendar linking, automatic capture and an external API are
not supplied in this stage.

CATALOGUE PRIVACY AND RECOVERY

The local Library catalogue contains plaintext metadata, including names,
paths, project names, notes and timestamps. Adding encrypted material does
not encrypt the catalogue. Do not put passwords, recovery keys, or secrets
in project notes. Keep the catalogue on storage you trust. A catalogue entry
is a reference to stored data, not a second copy of it.

Encryption is optional for supported formats. Compression alone is not
encryption; live repositories and restored files are not automatically
encrypted. Keep passwords and .rtrk recovery keys safe and separate. A
matching key can unlock its protected data. Losing required credentials and
recovery material may make the data unrecoverable.

Nothing is uploaded automatically. Network or cloud-synchronised locations
you select still follow that storage service's behaviour. Read PRIVACY.md.

ONE APPLICATION, UPDATED IN PLACE

The installed name remains Rat-Trap Desktop Preview 2 and the application
file remains Rat-Trap-Desktop-Preview-2.exe. This is an unsigned local preview,
not a signed or Microsoft Store release. No Python, Rat-Trap account or Codex
is needed for ordinary local use. There is no automatic updater.

If running an extracted payload, keep Legal and the supplied policy documents
alongside the executable. BUILD-MANIFEST.json is build evidence, not a digital
signature. When installed with Setup, this document becomes README-PORTABLE.txt;
README-FIRST.txt then provides the installer-specific instructions.

TEST SAFELY

Use copies first. Save archives outside their source folders and restore into
a separate empty folder. Check restored contents. Keep originals and an
independent backup; do not rely on a preview as your only copy. Wait for work
to finish before closing the app or disconnecting storage.

Windows, SmartScreen, antivirus or organisational policy may warn about or
block unsigned software. If blocked or uncertain, stop and ask your
administrator or support. Do not disable security protection.

The catalogue and stored work are kept when the application is uninstalled.
Removing the catalogue manually does not remove the referenced archives.
Removing stored files outside Rat-Trap can leave catalogue references missing.
