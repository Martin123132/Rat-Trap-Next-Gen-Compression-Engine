START HERE

This is an unsigned Windows 64-bit beta for testing. It is not a Microsoft
Store package, a certified release, or a promise that every Windows security
policy will allow it to run. Keep an independent backup of anything important.

PORTABLE ZIP: HOW TO START

1. Save the ZIP somewhere you can find it, such as Downloads.
2. Right-click the ZIP and choose Extract All. Choose a new folder.
3. Open the extracted folder and double-click Rat-Trap.exe.

Extract the whole ZIP before running the app. Keep its Legal folder and the
other included documents together with Rat-Trap.exe. Do not run the app from
inside the ZIP. No separate Python installation, Rat-Trap account, or internet
connection is needed for local file operations.

If this README came with the separate beta installer, complete that installer
and launch Rat-Trap from its shortcut; the ZIP extraction steps do not apply.

WINDOWS SECURITY WARNINGS

The beta executable and beta installer are not Authenticode-signed. Windows,
SmartScreen, antivirus software, or an organisation's security policy may warn
about or block them. A warning is not proof that a file is safe or unsafe.
Obtain the beta from the person or organisation you trust to supply it. If
blocked or unsure, stop and ask your administrator or the support contact
below. Do not disable security protection to run the beta.

SHA256SUMS.txt contains checksums for every other file in this package. These
help detect damaged or changed files; a checksum supplied with the same download
does not independently prove who published it or replace a digital signature.

TRY A SAFE FIRST ROUND TRIP

1. Make a small test folder containing COPIES of a few ordinary files.
2. Open Rat-Trap and select those copies as the input for compression.
3. Save the resulting archive outside the input folder, under a new name.
4. Restore the archive into a different, empty test folder.
5. Check the restored files against the originals, including their contents.

Use copies for all beta compression and restoration tests. Do not overwrite
your originals, restore over a working folder, or treat a beta archive as your
only backup. Check that the destination has enough free space. Wait for an
operation to finish before closing the app or disconnecting its storage.

PASSWORDS, ENCRYPTION, AND RECOVERY

Encryption is optional and must be explicitly selected for supported formats.
A .gmw file is not necessarily encrypted, and a live Rat-Trap repository is
not encrypted merely because Rat-Trap created it. Compression alone does not
make information private.

Keep passwords and .rtrk recovery-key files safe and separate from protected
data. A matching recovery key can unlock that data; do not share it or attach
it to a support email. Losing the required password and recovery material can
make protected data unrecoverable. Restoration may produce unencrypted files.

UPDATES AND REMOVAL

This direct-download beta has no automatic updater. Obtain any future version
from a trusted source and read its release instructions before replacing this
one. Do not overwrite the only copy of an earlier beta or your test data.

To remove the portable app, close it and remove only its extracted application
folder. First move out any archives, restored files, or other data you saved
inside that folder. If you used the installer, use Windows Apps settings to
uninstall it. Removing the application does not automatically remove archives,
repositories, recovery keys, exports, or restored files stored elsewhere. Keep
or delete those yourself. Local diagnostic files may also remain under:
%LOCALAPPDATA%\Two Hands Network Ltd\Rat-Trap\Diagnostics

PRIVACY AND SUPPORT

File processing is local. Rat-Trap does not automatically upload your files or
diagnostics. A network/cloud-synchronised folder you choose is subject to that
storage service's own behaviour. Read PRIVACY.md for details and SUPPORT.md for
troubleshooting and security-report guidance.
